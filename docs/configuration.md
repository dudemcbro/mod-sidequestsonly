# Configuration

The options in `mod_sidequestsonly.conf`.

Copy `conf/mod_sidequestsonly.conf.dist` to your config directory's `modules/` folder as
`mod_sidequestsonly.conf`. This is optional: the default is enabled.

| Option | Default | Meaning |
|---|---|---|
| `SideQuestsOnly.Enable` | `1` | `0` stops answering the addon and naming quests in NPC dialogs. |
